# spektt.com

The marketing, legal and deep-link website for Spektt. TanStack Start (Vite 8 + Nitro 3), served by a
Cloudflare Worker. Read `CLAUDE.md` before changing anything.

```bash
npm run dev      # http://localhost:3000
npm run build    # production build (.output/)
```

A push to `main` is a production deploy.
